# 솜주먹 스파링 (somjumeok-boxing)

거실 퍼즐매트 위에서 꼬마 둘이 글러브를 끼고 스파링하는 3D 브라우저 게임 시제품입니다.
`index.html` 파일 하나로 동작하며 휴대폰 브라우저 플레이를 기준으로 만들었습니다.

## 실행
- `index.html`을 브라우저로 엽니다. Three.js(r128)를 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- 사이트: https://somjumeok-boxing.github.io/ (휴대폰에서 링크로 바로 플레이)

## 캐릭터
- 감자(남자아이)와 토마토(여자아이). 혼자 할 때 시작 화면에서 내가 할 캐릭터를 고르면 나머지는 컴퓨터가 맡습니다.

## 조작
| 동작 | 휴대폰 | 키보드 |
|---|---|---|
| 이동 (앞뒤·양옆) | 왼손: 화면 왼쪽을 끌기 (떠다니는 조이스틱) | WASD / 방향키 |
| 한 팔 펀치 (빠르고 약함) | 오른손: 화면 오른쪽 톡 | J / Space |
| 두 팔 빙글 펀치 (느리지만 세고, 맞으면 다운) | 오른손: 화면 오른쪽에서 위로 밀기 | I |
| 가드 (누르는 동안) | 오른손: 화면 오른쪽 꾹 누르기 | K / Shift |
| 숙이기 (0.6초 후 자동으로 일어남) | 오른손: 화면 오른쪽에서 아래로 밀기 | L |
| 뒤로 빼기 (0.5초, 타이밍 맞으면 주먹 회피) | 오른손: 화면 오른쪽에서 옆으로 밀기 | H |

- 옆에서 보는 고정 카메라. 조이스틱 오른쪽 = 화면 오른쪽, 위 = 화면 안쪽.
- 두 아이는 항상 서로를 바라보고, 펀치를 뻗는 동안에는 방향이 고정됩니다(옆으로 비켜 피하기 가능).
- 네모난 퍼즐매트(4x4 조각) 밖으로는 못 나갑니다(보이지 않는 벽). 가드 중에는 느리게 걷습니다.

## 움직임
- 영상 속 아이들처럼 다리를 벌리고 무릎을 굽힌 엉거주춤 자세로 제자리에서 콩콩 뛰고, 앞뒤로는 성큼성큼, 옆으로는 게걸음으로 걷습니다.

## 도발
- 조이스틱 위 👋(두루와)·🕺(춤) 버튼으로 상대를 도발합니다. 두루와는 1.2초, 춤은 유행 춤 'L을 가져가~ 크림치즈허니'(2.4초)이고, 동작하는 동안은 빈틈이 생기지만, 펀치·가드·숙이기·빼기를 하면 바로 멈추고 그 동작으로 넘어가요. 컴퓨터도 가끔 도발해요.

## 일시정지
- 오른쪽 위 ⏸ 버튼(PC는 Esc)으로 계속하기·다시 시작·홈으로·게임 끄기를 고를 수 있습니다. 온라인 대결 중에는 게임이 멈추지 않습니다.

## 진동
- 내 펀치가 들어가면 짧게, 카운터는 조금 길게, 어퍼컷은 세게 두 번, 이기면 축하 리듬으로 울립니다(안드로이드 크롬). 아이폰은 웹 진동이 없어 iOS 17.4+ 스위치 햅틱으로 가볍게 톡(어퍼컷 2번, 승리 3번) 울리며, 기종·iOS 버전에 따라 안 될 수 있습니다.

## 규칙
- 시작할 때와 라운드가 바뀔 때 3초 동안(3·2·1·FIGHT!) 시계가 멈추고 서로 때릴 수 없습니다.
- 3판 2선승: 라운드마다 체력 100, 60초. KO 또는 시간 종료(체력 많은 쪽 승)로 라운드가 끝나고, 먼저 2라운드를 이기면 최종 승리.
- 가드: 피해 2만 받음. 숙이기: 펀치를 완전히 피함. 주먹이 닿지 않는 거리면 헛손질.
- 숙여서 피한 직후 펀치 → **어퍼컷** (다운).
- 상대 펀치가 나가는 순간 맞히면 **카운터** (다운). 연속 3대 맞아도 다운.
- 휘두르기에 맞아 다운되면 팔이 휩쓸고 간 방향으로 얼굴부터 "철퍼덕" 엎어졌다가(어퍼컷은 뒤로) 다시 일어나고, 일어난 직후 잠깐 자동 가드.
- 체력이 0이 되면 KO, 다시 일어나지 못합니다.
- 쉬지 않고 연타하면 숨이 차서("헉헉…") 펀치가 느려지고 반격당하기 쉽습니다.

## 친구와 온라인 대결
- 시작 화면 오른쪽 위 공유 아이콘으로 게임 주소를 친구에게 보낼 수 있습니다.
1. 시작 화면에서 **친구와 온라인 대결**을 누릅니다.
2. 방장은 감자/토마토 중 캐릭터를 고르고 **방 만들기**를 누른 뒤 **초대 링크 보내기**로 카톡 등에 링크를 보냅니다(공유창이 없으면 링크가 복사됩니다).
3. 친구는 링크를 열고 이름을 넣은 뒤 **참가**를 누르면 남은 캐릭터가 됩니다(4자리 코드를 직접 넣어도 됩니다). 연결되면 방장이 **시작!**을 누릅니다.
- [PeerJS](https://peerjs.com/) 무료 연결 서버로 서로를 찾은 뒤 휴대폰끼리 직접 연결합니다(가입 불필요).
- 방장 폰이 판정을 맡고 상태를 초당 20번 보내며, 참가자 폰은 조작만 초당 30번 보냅니다.
- GitHub Pages 주소에서 동작합니다. Claude 아티팩트 링크에서는 실시간 연결이 막혀 있어 온라인이 되지 않습니다.
- 회사·학교 와이파이처럼 직접 연결을 막는 네트워크에서는 연결이 안 될 수 있습니다(그럴 땐 휴대폰 데이터로).

## 무대와 연출
- 배경: 라운드마다 바뀝니다. 1라운드 밝은 거실(파랑·노랑·회색 퍼즐매트), 2라운드 체육관(체크무늬 매트·샌드백), 3라운드 햇살 좋은 풀밭(벽돌 담장·창고·마른 나무).
- KO: 슬로모션으로 쓰러지는 아이를 클로즈업한 뒤 이긴 아이를 비추고, 플레이어가 이기면 꽃가루.
- 성능: 기기 화면 배율을 최대 1.5로 두고, 2초 평균 프레임이 느리면 해상도·그림자를 단계적으로 낮춥니다.

## 난이도 (컴퓨터 '밤톨')
쉬움 / 보통 / 어려움 / 헬🔥. 공격 전 예고 시간, 반응 속도, 방어 확률, 반격 확률이 달라집니다. 헬은 예고가 거의 없고 쉴 틈 없이 몰아치며, 컴퓨터 펀치가 더 아프고 어퍼컷을 노리면 바로 막습니다.

## 구조
- 캐릭터 모델은 블렌더 스크립트 `tools/build_chars.py`로 만든 `chars.glb`를 불러와 관절 그룹에 입힙니다.
  다시 만들기: `pip install bpy` 후 `python tools/build_chars.py chars.glb`
  (파일로 열면 브라우저가 glb를 못 불러와 기본 도형으로 보입니다. 로컬 서버나 GitHub Pages로 여세요: `python3 -m http.server`)
- 캐릭터는 모델 파일 없이 구·원기둥으로 코드에서 조립합니다 (`makeFighter`).
- 동작은 관절 각도 포즈를 보간해서 만듭니다 (`targetPose`, `applyPose`, 다리 IK).
- 나중에 Blender/Mixamo/AI 3D 생성 모델(glTF)로 캐릭터만 교체할 수 있게 게임 로직과 분리돼 있습니다.
